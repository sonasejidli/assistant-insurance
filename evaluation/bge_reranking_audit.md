# Reranker audit before the experimental integration

The baseline already loads `BAAI/bge-reranker-v2-m3`. The running image resolved it to cached commit `953dc6f6f85a1b2dbfca4c34a2796e7dde08d41e`. This is a comparison between policies using the same checkpoint. The baseline is not a different model.

- Dense search resolves child-vector hits to unique parent passages before RRF. RRF fuses those parent ranks with BM25. The cross-encoder receives the contextualized retrieval query and a full parent passage as a two-string pair. The parent text carries insurance type, law name and number, chapter, section, article, and clause where available. Neither side receives E5 prefixes or diacritic folding. [BGE model card](https://huggingface.co/BAAI/bge-reranker-v2-m3)
- The active model and tokenizer both reported an 8,192-token maximum for the combined pair. The underlying position table has 8,194 positions. The tokenizer truncates from the right, and a deliberately overlong pair came out of baseline preprocessing at exactly 8,192 tokens. The baseline does not check whether the truncated material contains an exception.
- BM25 and dense search each default to 50 candidates. The baseline reranks a 24-parent shortlist, expanded for requests that need more hits. It reserves up to four leaders per active retrieval branch and fills the rest from fused order. The unscored tail stays in RRF order. Normal answer selection starts from five results and can add related parent context.
- The running CrossEncoder used CPU, default batch size 32, and sigmoid activation for its single score. No CUDA device was visible. The application checks that each pair has one finite score, sorts descending, and preserves candidate order on ties. A reranker failure falls back to fused order.
- The previous paired synthetic benchmark measured baseline reranking at 2,784 ms p50 and 3,201 ms p95 using a 12-pair shortlist. That run used four CPU threads and a 43-passage fixture. These are historical fixture timings and cannot predict an actual 30–50-parent rerank.
