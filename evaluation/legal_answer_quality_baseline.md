# Execution path recorded before benchmark changes

The request entry point is App/main.py ask. It calls resolve_request and plan_query for normalization, context reconstruction, intent, and question parts. The optional planned retrieval path adds query variants, decomposition and routing. The text retriever graph uses BM25 and dense parent retrieval, weighted RRF, the cross-encoder reranker and top-k selection. BM25, dense and reranked candidate scores are available in opt-in run captures. Exact article lookups can bypass the hybrid stages.

Evidence assembly works on the already-ranked parents and can add verified cross-references and surrounding passages. When LEGAL_SOURCE_AUTHORITY is enabled, the authority layer annotates evidence and limits the existing structured generator and its judge to eligible normative references. It keeps contextual material and exposes declared dates and unresolved conflicts. The structured generator records raw attempts and separates citations, binding checks and the faithfulness verdict. App/main.py formats the final answer and records the response decision. Langfuse remains optional and ordinary telemetry does not carry raw evaluation answers.

The hardened verifier operates offline on a separate exact-answer and passage-bound input. It has a bounded technical witness catalog and trusted fact and completeness inputs. It is not a production middleware stage. The end-to-end harness will replay the actual generator's accepted claims through this existing gate without replacing the captured user-facing response.

The existing capture context records request flow, scores, evidence, raw outputs and timings. Its private run storage and checksum helpers can also persist deterministic fixtures. The platform exposes normalized and standalone questions, plan parts and typed date assertions, but no general extraction API for legal entities or parsed dates from free text. The evaluation must report those unavailable separately. The original 43-fixture verifier comparison was captured before implementation.
