## Historical versions

File SHA-256 identifies the exact bytes used by extraction. [Source registry](../data/legal_source_versions.json) associates available provenance with those bytes and ignores entries when the digest changes. Unknown metadata remains null. `/documents` exposes the version fields and existing `/documents/{name}/versions` lists versions preserved as `family@digest.ext`. Use `python -m evaluation.archive_legal_source FILE --family FAMILY --directory STAGING_DIRECTORY` to stage new immutable copies before review. Supply verified `published_at`, `effective_from`, `effective_until`, `amended_at`, `is_current`, `source_url`, and `retrieved_at` where available. `filters.as_of` on `/ask` and `/search` selects only versions with an effective period covering the requested date. For a verified current version with no end date, the observation date bounds applicability. Existing source files and production indexes were untouched.
